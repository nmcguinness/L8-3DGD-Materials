Blend Modes Explorer

A blend mode decides how the colour your material outputs is combined with the colour already on screen. Unreal and Unity use different names, but both set the same two numbers on the graphics card. Learn the equation once and you can read either engine.

src sourceThe colour your material outputs for this pixel. Its alpha is the Opacity pin in Unreal and Base Map alpha in Unity.
dst destinationThe colour already in the frame buffer at this pixel, from everything drawn earlier.
The blend equationresult = src × SrcFactor + dst × DstFactor. A blend mode is a choice of the two factors.
Linear values, 0 to 1Engines blend linear colour values before tone mapping. A result above 1 is kept on an HDR target and clamps to white on an LDR one.

Common pitfalls

  • Using Translucent for foliage. Leaves need only a yes or no per pixel. Masked gives you depth writes, correct sorting and full lighting. Translucent gives you sorting errors and overdraw for no visible gain.
  • Overdraw. Every translucent layer runs its pixel shader and blends, even when ten layers cover the same pixel. Opaque surfaces hidden behind others are skipped by the depth test. Large stacked smoke sprites are a classic frame-rate killer.
  • Additive effects on bright scenes. An additive spark over a white sky adds to a value that is already at the top of the range. Test effects against both dark and bright backgrounds.
  • Expecting Modulate to brighten. With colour values between 0 and 1, multiplying can only darken. White does nothing and black gives black.
  • A straight-alpha texture in a premultiplied mode. The colour was never multiplied by alpha, so soft edges come out too bright and haloed. Either premultiply the texture or multiply colour by alpha in the material.
  • Missing depth. Translucent surfaces do not write depth, so effects that read the depth buffer, such as depth of field and decals, treat them as if they were not there.

Check your understanding

Predict first, then confirm with the stations above, then open the answer.

In station 1, choose Premultiplied and set alpha to 0. Which other mode does it now match?

Additive. DstFactor is 1 − 0 = 1, so the result is src + dst. At alpha 1 the destination is removed and it matches Opaque. One material can therefore hold both a solid part and a glowing part.

Which of the four modes in station 3 give the same picture in both orders, and why?

Additive and Modulate. Addition and multiplication give the same answer in any order. Translucent and Premultiplied scale the destination by (1 − a) at each step, so whichever disc is drawn last hides the most.

You draw a Modulate material with a pure white source. What changes on screen?

Nothing. Every channel of the destination is multiplied by 1. The pixel shader still ran, so you paid for a draw that had no effect.

Why does the Masked leaf in station 2 have a hard edge while the Translucent leaf has a soft one?

Masked compares alpha with the clip value and either keeps the pixel or discards it. There is no in-between. Translucent uses alpha as a weight, so a pixel with alpha 0.5 is half leaf and half background.

A Translucent material has alpha 1 everywhere. Is it now as cheap as Opaque?

No. It still skips the depth write, still has to be sorted, and is still shaded in the translucency pass. If alpha is always 1, switch the material to Opaque.
